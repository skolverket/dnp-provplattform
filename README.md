# Alternativ inloggning till Skolverkets provplattform om skolverket.se inte fungerar
Om Skolverkets webbplats (skolverket.se) ligger nere går det inte att använda det vanliga sättet att aktivera nedlåst läge på de digitala enheter som använder Safe exam browser (SEB) och logga in till provplattformen. Eleverna måste därför på annat sätt få åtkomst till den fil som startar och konfigurerar SEB. Nedan finns två alternativa sätt att starta SEB och logga in i provplattformen. Ni som huvudman eller skola väljer vilket sätt ni vill använda och säkerställer att alla i organisationen vet vad som behöver göras för att använda det alternativ ni valt.
<br/>

## De här eleverna påverkas inte:
- Elever som genomför prov på Chromebook. De kan starta provet som vanligt.
- Elever som är undantagna från nedlåst läge. De ska använda den här länken: [https://provplattformen.skolverket.se/engine/index.php/lms/login/path/sso_NP](https://provplattformen.skolverket.se/engine/index.php/lms/login/path/sso_NP)
 <br/>

## Två alternativ

Välj ett av alternativen nedan för att möjliggöra för elever att använda Safe exam browser om Skolverkets webbplats ligger nere.
<br/>
#### Alternativ 1: Distribuera länk till SEB-konfigurationsfil

1. Distribuera länken nedan till eleverna. Det kan ske genom e-post, meddelande i er lärplattform eller på annat sätt som når alla elever.

2. I vissa program och tjänster blir inte länken klickbar.
   - Blir den inte klickbar informerar ni eleverna om att de ska kopiera länken och sedan starta valfri webbläsare och klistra in länken där. Sedan måste de trycka på retur-tangenten, enter eller motsvarande.
   - Blir den klickbar för era elever räcker det att de klickar på den.
   
   I båda fallen följer eleverna sedan samma procedur som vanligt för att tillåta Safe exam browser att öppnas och sedan logga in i provplattformen.

4. Lösenord för att starta och avsluta SEB är 2526

Länk att sprida till eleverna:
sebs://github.com/skolverket/dnp-provplattform/raw/refs/heads/main/DNP.seb

Obs:
- Det är viktigt att eleverna kopierar hela länken.
- Länken fungerar bara på enheter som har Safe exam browser installerad.
<br/>

#### Alternativ 2: Distribuera SEB-konfigurationsfil

Om ni föredrar kan ni i stället för länk välja att distribuera filen till eleverna. Tillvägagångsättet för eleverna kan skilja sig åt beroende på vad de har för typ av digital enhet och på vilket sätt ni distribuerar filen. Instruktionen kan därför inte bli helt komplett, utan ni måste även själva testa vilka steg eleverna måste vidta och komplettera informationen till dem.

1. Ladda ned filen via länken nedan

2. Dela filen med eleverna via e-post, lärplattform, delad mapp eller på annat sätt.

3. Hur eleverna gör för att använda filen beror på hur ni distribuerat den, och vad eleverna använder för program och digital enhet. I många fall måste eleverna först spara ned filen och sedan dubbelklicka för att öppna den. Testa vad som gäller just hos er och informera eleverna.

4. Lösenord för att starta och avsluta SEB är 2526

[Länk för att ladda ned fil.](https://github.com/skolverket/dnp-provplattform/raw/refs/heads/main/DNP.seb) (SEB startas inte med denna länk)
<br/>
<br/>

## När webbplatsen fungerar igen

Så snart skolverket.se fungerar igen ska man starta bedömningsstöd via den ordinarie länken på sidan [Logga in med Safe exam browser](https://www.skolverket.se/prov-och-bedomning/provtjansten/om-skolverkets-provplattform/logga-in-i-provplattformen/logga-in-med-safe-exam-browser).
